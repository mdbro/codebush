# Twelve-dimensional reference space

The default viewer projects a fixed graph in Euclidean **R¹²** onto a two-dimensional screen. It offers all **66 coordinate planes**, continuous rotations between them, a plane tour, rotation scrubbing, source reading, and test inclusion. The **Tree view / 12D view** button beside the logo switches modes in the same window, using the existing GPU allocations. `--tree` starts in the directory atlas.

```bash
./scripts/run.sh /home/mdwbr/llama.cpp
./scripts/run.sh /home/mdwbr/llama.cpp --tree
```

The 2D tree executable and source before this extension are preserved in `D:\Codetree\evidence\12d-baseline`.

## Geometry and visibility

Each file has one deterministic, fixed position `x ∈ R¹²`. Each directed reference is the straight segment joining its two file positions. Positions are laid out once, before rendering. A deterministic clearance relaxation spaces annotations in the coordinate planes before those positions are frozen; it never moves anchors in response to the current view. The view uses the first two rows `u, v` of a proper orthogonal matrix `R`:

```
screen_anchor(x) = (u · x, v · x)
R Rᵀ = I, det(R) = +1
```

A transition factors the relative orientation into Givens rotations and varies their angles with a quintic time parameter. Every intermediate matrix is a product of proper rotations. Twelve-dimensional lengths, angles, and endpoint incidence remain invariant. Projected distances can shrink, and projected segments can cross without forming new graph vertices. There is no perspective camera or intermediate three-dimensional scene. This follows the [Givens rotation construction documented by LAPACK](https://www.netlib.org/lapack/lawnspdf/lawn150.pdf).

Source panels and labels are screen-facing annotations attached to projected anchors. Their text stays readable in the image plane; they are not claimed to be rigid surfaces embedded in twelve dimensions. The geometric invariant applies to file anchors and their reference segments. Selecting a panel raises it above other annotations and makes its background opaque. Shift-click cycles panels whose projections overlap; O lists every candidate under the pointer in the sidebar. Hover reveals full file paths. This changes annotation stacking, not their anchors or reference geometry.

The user-approved dimension convention is a deterministic partition of references across the 66 planes. A stable hash of source and target paths assigns each reference to one plane. **Plane membership is a graph filter, not a claim that an edge's 12D displacement has only two nonzero components.** The coordinates have no inferred semantic meanings such as language or directory. This convention allows distinct subsets while retaining every resolved link somewhere.

For an intermediate orientation, plane `(i,j)` receives weight:

```
wᵢⱼ = (uᵢ vⱼ − uⱼ vᵢ)²
Σ wᵢⱼ = 1
```

At a coordinate plane its weight is one and all other weights are zero. During a rotation, the weights vary continuously. Links use the fourth root of the weight as their opacity; a file's opacity is the maximum of its incident visible links. Weights below `10⁻⁶` are suppressed consistently in CPU selection and GPU rendering. A file with no visible incident references does not appear. Test exclusion removes test-only references before visibility is computed.

Files use tall source panels, with long lines soft-wrapped underneath their original line number. The current squarified directory atlas fits complete source into each allocated tile using uniformly scaled glyphs and adjacent continuation columns where needed. Both views share the source panels. No source lines are discarded. See [the current visual repair](VISUAL-REPAIR.md).

Before a rotation begins, the camera eases over 280 ms to a fixed frame covering its entire path. The bounds include all connected files and their panel extents, including files absent at both endpoints. Uniform samples of the Givens angle parameter are expanded by the analytic displacement bound `||x|| * sum(abs(angle)) / (2 * 64)`, plus float rounding margin. This covers extrema between samples. The graph then rotates for 1.2 seconds within that fixed frame. Scrubbing, test changes, and window resizing retain the fit. Reading, panning, or zooming pauses rotation and gives control to the user; the next rotation frames the graph again.

## Controls

- **Tree view / 12D view**: switch modes without source reads, indexing, or GPU reuploads. Each mode retains its camera and selection; the test filter is shared.
- Click a cell in the triangular plane matrix to rotate to that coordinate pair. Brighter cells contain more links.
- `[` / `]`: previous / next plane. Space: start or pause the plane tour.
- The bottom slider scrubs the current rotation and holds the chosen orientation.
- Wheel: pointer-centered zoom. Drag: pan. `F`: fit the active files.
- Click a source card, endpoint caption or connected-file row to trace its links without zooming away from visible graph context. Enter or double-click a source card reads its full source. **Back to links** or Escape restores the previous graph camera. Shift-click cycles overlapping panels; O lists all candidates under the pointer. Hover reveals full paths.
- Selecting a file opens its visible incoming/outgoing references with source-line evidence; **All files / Links** switches the sidebar. Click an entry to follow it. Selected incident links and endpoint captions are emphasized while all other included links remain drawn.
- `/` or Ctrl F: filter connected file paths. `T`: include or hide tests.
- Ctrl O: open a source folder. Ctrl R: reload. F11: fullscreen. `?`: help.

## Reference resolution boundary

The graph resolves static file references within indexed source. Rust uses `syn` for external modules, path attributes, use trees, qualified paths that resolve to files, and source inclusion macros. External-module declarations identify physical parent files, including separate binary and library roots. Cargo manifests supply declared library, binary, test, benchmark, and example roots, including custom paths such as `tests/tests.rs`. Test-only module ancestry propagates to incident references. Manifests remain outside the displayed source. This uses the [Cargo target model](https://doc.rust-lang.org/cargo/reference/cargo-targets.html). When a whole-file AST parse fails but tokenization succeeds, valid use/module items are recovered independently; the partial parse failure remains reported. Rust path resolution follows the [module](https://doc.rust-lang.org/reference/items/modules.html) and [path](https://doc.rust-lang.org/reference/paths.html) rules where supported. Other extractors cover C/C++/shader includes, JS/TS imports and require calls, Python imports, Go package imports, JVM imports, and several literal source-loading forms.

Each edge retains its source file, target file, source line, reference spelling, kind, test classification, and plane. Comments and unrelated symbol co-occurrence do not create edges. Unresolved/external references, Rust parse failures, manifest errors, and unsupported languages are separately reported in `dependencies.json`.

This is not a compiler-complete dependency engine. Build-time include paths, package aliases, generated modules, macro expansion, runtime-computed imports, and language-specific symbol binding can require project configuration unavailable to the static resolver. The application does not claim that all such references have been resolved. Only resolved local links can be displayed; the complete source remains accessible through `--tree`.

## Residency and performance evidence

Both source/test views, full source geometry, image caches, all file positions, plane memberships, and edges are uploaded at load time. Rotation uploads only the projection basis and plane weights; static graph/source buffers are retained. GPU shaders project both reference endpoints and source anchors using the same basis. Near views use the resident glyph geometry, and overview views sample resident source images. The default allocation cap remains 30 decimal GB, configurable up to 32 GB.

The 120fps requirement is a measurement gate, not a consequence of residency. The earlier tree failed this gate; new 12D results are recorded independently under `D:\Codetree\evidence\12d-round-N`. Offscreen 8K rendering does not certify physical 8K/120 presentation on the attached 4K/60 display.

The mathematical contract tests exhaust all 4,356 ordered coordinate-plane transitions at multiple intermediate times, interrupted transitions, determinant/orthogonality/distance invariants, and endpoint continuity. Reference fixtures check directed edges, evidence, complete plane coverage of resolved edges, false comment/string/property-call references, parent-module ownership, import recovery after unsupported syntax, and absence of disconnected nodes in every plane/test combination. The original four-review cycle is recorded in [12D validation](12D-VALIDATION.md); the subsequent visual-repair cycle is capped at five reviews. Reload and folder replacement release the old source allocations and upload new ones on a worker, while the window continues rendering a loading view.
